how it works

Three status codes. That's the whole protocol.

Tollway speaks x402, the payment-required flow HTTP always reserved but never shipped. No API keys for your customers, no checkout pages, no invoicing. Agents pay in-band.

402

Challenge

An unpaid request gets a signed challenge: the price, the network, and where to pay. Machine-readable, so agents handle it without a human in the loop.

verify

Verify

The agent pays and retries with proof. Tollway verifies it through your facilitator, Coinbase or PayAI: settlement-gated, nonce-cached, replay-safe.

200

Serve

Your handler runs exactly as before, and the response carries a signed receipt. Every event streams to your console, where the business half happens.

the open sdk

Start with the SDK. Free forever, no account.

One line of middleware turns any route into a tollgate. MIT licensed, facilitator-neutral, fully functional standalone. The cloud is additive, never required.

Your framework, one line

Express and Hono in TypeScript, FastAPI in Python. Same wire format and receipts everywhere, held to golden fixtures byte for byte.

No keys custodied, no lock-in

Verification is delegated to the facilitator of your choice. Settlement addresses are yours. Swap rails by changing one option.

Abuse handled in core

Token buckets, automatic 429s, and a payer denylist ship in the open package. Event delivery stays off the halt path, so the cloud can never take your API down.

server.js, a paid API in 20 lines 
import express from "express";
import { tollway, coinbaseFacilitator } from "@tollway/gate";

const app = express();

app.use("/v1/report", tollway({
  price: "$0.004",
  network: "base-sepolia",
  payTo: process.env.TW_ADDRESS,
  facilitator: coinbaseFacilitator(),
  apiKey: process.env.TW_KEY, // optional: lights up the console
}));

app.get("/v1/report", (_req, res) => {
  res.json({ report: "the paid content" });
});

app.listen(3000);
