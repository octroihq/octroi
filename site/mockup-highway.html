how it works · three gates, one road

Three status codes. That's the whole protocol.

Tollway speaks x402, the payment-required flow HTTP always reserved but never shipped. No API keys for your customers, no checkout pages, no invoicing. Agents pay in-band, gate by gate.

402

Challenge gate

An unpaid request hits the first gate and gets a signed challenge: the price, the network, and where to pay.

verify

Verify gate

The agent pays and retries with proof. Tollway checks it against your facilitator: settlement-gated, nonce-cached, replay-safe.

200

Open lane

Your handler runs exactly as before. The response carries a signed receipt, and the toll streams straight to your ops center.

server.js, a paid API in 20 lines 
import express from "express";
import { tollway, coinbaseFacilitator } from "@tollway/gate";

const app = express();

app.use("/v1/report", tollway({
  price: "$0.004",
  network: "base-sepolia",
  payTo: process.env.TW_ADDRESS,
  facilitator: coinbaseFacilitator(),
  apiKey: process.env.TW_KEY, // optional: opens the ops center
}));

app.get("/v1/report", (_req, res) => {
  res.json({ report: "the paid content" });
});

app.listen(3000);
